🚛 Camion Export Processor …

Sube el packing list (.xlsx), opcionalmente los documentos T1 (.pdf, nombre debe contener T1) y el documento DOC (.pdf, nombre debe contener DOC) si quieres validar el XLSX antes de procesar. La herramienta genera un XLSX enriquecido con la hoja Procesado_Camion.

Formato permitido: XLSX
Opcional. Uno o más PDFs — el nombre debe contener T1 (ej. T1_1.pdf)
Un PDF — el nombre debe contener DOC (ej. 20260310_DOC.pdf)
Úsalo solo si el XLSX ya fue revisado/corregido manualmente y quieres reprocesar sin regenerar PDF_VALIDADO.

Endpoint: POST /api/camion/batches
